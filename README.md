# Habittuo

A simple habit tracking app for iOS, built with SwiftUI.

## About

Habittuo lets you keep track of activities you want to do more consistently — whether that's reading, exercising, learning something new, or anything else. You add the activities, you decide how to track them.

## Features

- Add and manage custom activities with a name and description
- Track completion count for each activity
- Rename activities directly from the detail screen
- Swipe to delete activities

## Built With

- Swift & SwiftUI
- Xcode 16

## Status

Early stage. Data does not persist between sessions yet — UserDefaults support is planned.
